## 本轮修复项

1. 改为服务端 SQLite 数据持久化，不再依赖 localStorage 业务数据。
2. 线索转换使用数据库事务且禁止重复转化或客户端伪造转换关系。
3. 使用整数分汇总回款，合同金额不允许低于已回款数，禁止超额登记。
4. 登录认证、租户过滤、角色限制、操作审计与 CSV 导出。
5. 修正金额小数精度容差，允许 0.29 元等合法金额。
6. 记录详情弹窗去掉无效“保存”操作。

## 尚存问题与上线阻断条件

- **G0 录屏基准**：未通过，无法声称按用户视频 1:1 复刻。
- **G1 浏览器视觉/交互验收**：未通过，浏览器启动环境受限；需要在用户 Chrome/Edge 中验证 UI。
- **G2 核心接口集成**：通过。未覆盖完整压力、并发写入和极端网络故障。
- **G3 访问控制基础测试**：通过；没有行级权限、MFA、防爆破限流、安全渗透验证。
- **G4 生产部署**：有 Dockerfile、Compose、备份脚本和文档；**未开展线上部署/灾备演练**。

本包适合作为可本地部署的 CRM V1.0 功能工程、后续视觉复刻底座。不建议在缺少 TLS、安全加固、数据合规评估前直接公网开放。
