# CRM 项目应用 PRD — V1.0

## 1. 建设目标与来源

目标：复刻用户录屏中的 CRM，并对标 Salesforce、HubSpot、纷享销客。录屏 `10186_raw.mp4` 已知存在，但材料化后在执行容器不可访问，故此版在功能层先建设**独立通用 CRM**，未能确立原系统品牌、菜单、截图/时间码、像素间距。无法作 1:1 一致性声明。

## 2. 用户角色

管理员：成员创建、数据操作、审计；经理：业务增删改查及审计；销售：数据新增编辑与导出；观察员：查看。注意尚无行级负责人隔离及字段级授权，不应存储高度敏感的客户秘密而不评估权限。

## 4. 数据与 API

统一实体：`leads`、`accounts`、`contacts`、`opportunities`、`tasks`、`activities`、`contracts`、`payments`。

- `GET /api/health` 健康检查。
- `POST /api/login`, `GET /api/me`, `POST /api/logout`, `POST /api/password`。
- `GET/POST /api/{entity}`；`GET/PATCH/DELETE /api/{entity}/{id}`。
- `POST /api/leads/{id}/convert`，不可重复转换；同事务写客户和线索状态。
- `GET /api/dashboard`；`GET/POST /api/users`；`GET /api/audits`。
- `GET /api/{entity}?format=csv`，导出日志记录。

SQLite 存储租户、用户、会话、JSON 业务记录与审计。金额 JSON 使用数字以兼顾离线零依赖；回款核验按**整数分**计算，避免该环节浮点汇总偏差。严格财务账本应迁移 Decimal/整数分落盘。

## 5. UI 信息架构

左侧导航：工作台、线索、客户、联系人、商机、任务、跟进、合同、回款、成员、审计。顶部：当前人员、修改密码、退出。主区域：指标、表格、工具栏、创建/编辑弹窗、商机看板，响应式折叠导航。

## 6. 安全与运维

默认仅回环地址访问；对外发布须 TLS 反代、防爆破限流、日志与告警、MFA、隐私合规评估。数据库持久卷+SQLite一致性快照。生产发布前要求实际浏览器验收、用户培训与风险评估。
